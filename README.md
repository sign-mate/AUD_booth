# AUD_booth

2026 소통이 흐르는 밤 Signmate 부스 체험 게임. 글로 적혀 있으면 누구나 이해할 수 있을까?라는 질문을 던지는 짧은 O/X 체험 게임입니다.

## 실행

index.html을 브라우저에서 열면 됩니다. 서버와 인터넷 연결이 필요 없고, 파일 하나로 동작합니다.

## 구성

- 1단계: 제주어, 찌아찌아어 O/X 문제
- 2단계: 문자 메시지 O/X 문제
- 문제와 문구는 index.html 상단의 DATA에서 수정

## 운영

- 운영자 패널: Ctrl+Shift+A 또는 행사명 3초 길게 누르기
- 패널에서 참여 수, 완료율, 평균 소요 시간, 문제별 정답률 확인 및 CSV 내보내기
- 기록은 해당 기기의 브라우저에 저장되므로, 행사 후 CSV를 꼭 내려받을 것
- 90초간 입력이 없으면 처음 화면으로 자동 초기화되고 이탈로 기록

## 파일

- index.html: 게임 본체
- signmate_booth_plan.md: 부스 기획 초안
